# Co-op Engine Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Co-op a playable online match — one human Void Lord placing monsters from a tier-point budget against 1–4 hero players — on a new 25×25 map, by generalising the Vanilla engine into sides plus per-mode rules.

**Architecture:** Every unit gets a `side`; a `Sides` helper replaces seat-based friend/foe checks. A `ModeRules` strategy (`VanillaMode`, `CoopMode`) owns start, pre-battle phases (setup, draft), the turn schedule (as numbered *slots*), activation limits and victory; `BattleRules`, movement, combat, abilities, conditions and terrain stay shared and ask the mode through `Modes::ofState($state)`. `GameService` adds lobby role commands and Co-op projections; the Blazor client gains a Void Lord setup panel, a Co-op draft and multi-seat battle display.

**Tech Stack:** PHP 8.3 dependency-free rules engine with the plain-PHP test runner (`php api/tests/run.php`); JSON scenarios generated by `api/tools/build-terrain-scenarios.php`; .NET 10 Blazor with C# records, xUnit and bUnit.

**Spec:** `docs/superpowers/specs/2026-10-13-coop-engine-core-design.md`

## Global Constraints

- PHP files start with `declare(strict_types=1);`. JSON property names are camelCase. Contract changes are additive with safe defaults so old snapshots deserialize.
- The server is authoritative for every rule. The client sends only commands listed in this plan.
- **Refactor gate:** after Tasks 1–2, `php api/tests/run.php` passes with **no edits to existing test assertions**. The only existing-test edits allowed anywhere in this plan are the ones a task names explicitly (catalog counts in Task 3, Portal Watch references in Task 4, the Co-op refusal test in Task 8).
- Vanilla `state.result` stays exactly `['reason' => 'annihilation', 'winningSeatId' => …]`. `winningSide` is added only in the projection (Task 9).
- Monster cost by tier: common 1, elite 2, boss 4. Budget = `basePoints + pointsPerHeroPlayer × heroPlayerCount`; Void Reaches uses base 4, 8 per hero player.
- Monsters with `hidden: true` are never offered or accepted.
- Hero player: 2 heroes + 1 six-unit army (8 units). Up to 5 activations per turn; non-hero activations capped at `3 + heroes of that seat defeated`. Void Lord: up to 5 activations of any monsters.
- Co-op schedule: `H1 → VL → H2 → VL → … → Hn → VL`. A hero seat with no units on the board is skipped together with the Void Lord turn after it.
- Co-op victory: heroes win when no `void` unit remains (`reason: monstersDefeated`, `winningSide: heroes`, `winningSeatId: null`); the Void Lord wins when no `isHero` unit of side `heroes` remains (`reason: heroesDefeated`, `winningSide: void`, `winningSeatId: <void lord seat>`). Monsters are checked first.
- Unit ids: monsters `v-m1`, `v-m2`… (never reused); hero players `s{n}-hero1`, `s{n}-hero2`, `s{n}-u1`…`s{n}-u6`, where `n` is the seat's 1-based position in `state.seats`.
- New error codes are exactly: `voidLordRequired`, `heroPlayerRequired`, `voidLordTaken`, `notVoidLord`, `budgetExceeded`, `outsideSpawnZone`, `hexOccupied`, `hexNotEnterable`, `unknownMonster`, `setupConfirmed`, `setupEmpty`, `heroesComplete`, `heroesActivationRequired`, `invalidCoopScenario`.
- New events are exactly: `monsterPlaced`, `monsterRemoved`, `setupConfirmed`, `voidLordChanged`.
- Battle Royale still refuses to start with `modeNotPlayable`.
- Keep each task green before committing. Commit messages end with the session attribution lines from the conversation.

## Review Focus

1. **A seat of one side activating or attacking with an ally's unit.** Hero players are allies but may only command their own units; `notYourUnit` must still fire for an ally's unit. Task 7 pins this.
2. **A hero player wiped out mid-round.** Their turn and the Void Lord's response to them are skipped; round counting and effect/stun expiry (`nextTurnNumberOf`) stay correct. Tasks 2 and 7 pin the schedule and expiry with a skipped seat.
3. **Setup commands from the wrong seat or after confirmation.** A hero player's `placeMonster` gets `notVoidLord`; the Void Lord's `placeMonster` after `confirmSetup` gets `setupConfirmed`. Tasks 5 and 6 pin both.
4. **Malformed payloads** (arrays where strings are expected, missing `hex`, non-string `seatId` on `assignVoidLord`). These must produce rule errors, never PHP warnings or 500s. Tasks 5 and 8 pin them.
5. **Role changes after players readied.** Claiming, releasing or reassigning the Void Lord clears every ready flag, so a stale roster cannot start. Task 8 pins this.

`api/src/Rules/Vanilla/Sides.php`:

```php
<?php
declare(strict_types=1);

namespace BloodAndBanners\Rules\Vanilla;

/** Allegiance. A seat commands units; a side groups the seats whose units fight together. */
final class Sides
{
    /** One side per seat, as in a duel. */
    public static function perSeat(array $seatIds): array
    {
        $sides = [];
        foreach ($seatIds as $seatId) {
            $sides[(string)$seatId] = ['kind' => 'player', 'seatIds' => [(string)$seatId]];
        }
        return $sides;
    }

    public static function ofUnit(array $state, string $unitId): string
    {
        $unit = $state['units'][$unitId];
        return (string)($unit['side'] ?? $unit['seatId']);
    }

    public static function ofSeat(array $state, string $seatId): string
    {
        foreach ($state['sides'] ?? [] as $sideId => $side) {
            if (in_array($seatId, $side['seatIds'], true)) {
                return (string)$sideId;
            }
        }
        return $seatId;
    }

    public static function enemies(array $state, string $unitId, string $otherId): bool
    {
        return self::ofUnit($state, $unitId) !== self::ofUnit($state, $otherId);
    }

    public static function allies(array $state, string $unitId, string $otherId): bool
    {
        return !self::enemies($state, $unitId, $otherId);
    }

    /** Whether any unit of $sideId is still on the battlefield. */
    public static function anyAlive(array $state, string $sideId): bool
    {
        foreach ($state['units'] as $unitId => $unit) {
            if ($unit['hex'] !== null && self::ofUnit($state, (string)$unitId) === $sideId) {
                return true;
            }
        }
        return false;
    }
}
```

```php
namespace BloodAndBanners\Rules\Vanilla\Modes;

use BloodAndBanners\Rules\RandomSource;

/** What differs between game modes: start, the phases before battle, who acts next, activation limits and victory. */
interface ModeRules
{
    /** @return array{state: array, events: list<array>} */
    public function start(array $seatIds, array $board, RandomSource $random, array $options): array;

    /** Commands of the phases before battle (setup, draft). @return array{state: array, events: list<array>} */
    public function applyPreBattle(array $state, string $seatId, string $kind, array $payload): array;

    public function legalPreBattle(array $state, string $seatId): array;

    /** Turn slots in one round; slot 0 opens the round. */
    public function slotCount(array $state): int;

    public function seatAtSlot(array $state, int $slot): string;

    /** False when the slot's turn is skipped this time round. */
    public function slotLive(array $state, int $slot): bool;

    public function allowance(array $state, string $seatId): int;

    /** The mode's reason $unitId may not activate now, or null. */
    public function activationError(array $state, string $unitId): ?string;

    /** The match result once a side has won, or null. */
    public function victory(array $state): ?array;
}
```

```php
declare(strict_types=1);

namespace BloodAndBanners\Rules\Vanilla\Modes;

use BloodAndBanners\Game\GameServiceException;
use BloodAndBanners\Rules\Vanilla\Catalog;

final class Modes
{
    public static function for(string $mode, ?Catalog $catalog = null): ModeRules
    {
        return match ($mode) {
            'vanillaPvp' => new VanillaMode($catalog),
            default => throw new GameServiceException('modeNotPlayable', 'That game mode cannot be played in this version yet.'),
        };
    }

    public static function ofState(array $state, ?Catalog $catalog = null): ModeRules
    {
        return self::for((string)($state['mode'] ?? 'vanillaPvp'), $catalog);
    }
}
```

```php
final class VanillaMode implements ModeRules

    public const UNITS_PER_SIDE = 7;

    public function __construct(private readonly ?Catalog $catalog = null)
    {
    }

    public function start(array $seatIds, array $board, RandomSource $random, array $options): array
    {
        if (count($seatIds) !== 2) {
            throw new GameServiceException('modeNotPlayable', 'A Vanilla duel needs exactly two commanders.');
        }
        Placement::assertCapacity($board, self::UNITS_PER_SIDE);
        $initiative = (new InitiativeResolver())->resolve($seatIds, $random);
        $undecided = array_fill_keys($seatIds, null);
        $state = [
            'mode' => 'vanillaPvp',
            'phase' => 'draft',
            'seats' => $seatIds,
            'sides' => Sides::perSeat($seatIds),
            'board' => $board,
            'initiative' => ['rolls' => $initiative['rolls'], 'order' => $initiative['order']],
            'draft' => [
                'pickingSeatId' => $initiative['order'][0],
                'pickIndex' => 0,
                'firstSeatId' => null,
                'startBySeat' => $undecided,
                'heroBySeat' => $undecided,
                'armyBySeat' => $undecided,
            ],
            'units' => [],
            'effects' => [],
            'conditions' => [],
            'pending' => null,
            'turn' => Turn::idle(),
            'result' => null,
        ];
        return [
            'state' => $state,
            'events' => [MatchEngine::event('initiativeRolled', [], [
                'rolls' => $initiative['rolls'],
                'order' => $initiative['order'],
            ])],
        ];
    }

    public function applyPreBattle(array $state, string $seatId, string $kind, array $payload): array
    {
        return $this->draft()->apply($state, $seatId, $kind, $payload);
    }

    public function legalPreBattle(array $state, string $seatId): array
    {
        return $this->draft()->legalActions($state, $seatId);
    }

    public function slotCount(array $state): int
    {
        return 2;
    }

    public function seatAtSlot(array $state, int $slot): string
    {
        $first = $state['draft']['firstSeatId'] ?? $state['seats'][0];
        return $slot % 2 === 0 ? $first : self::other($state, $first);
    }

    public function slotLive(array $state, int $slot): bool
    {
        return true;
    }

    public function allowance(array $state, string $seatId): int
    {
        return min(4, self::alive($state, $seatId));
    }

    public function activationError(array $state, string $unitId): ?string
    {
        $unit = $state['units'][$unitId];
        if ($unit['isHero'] || !self::heroAlive($state, $unit['seatId'])) {
            return null;
        }
        $others = count(array_filter($state['turn']['activated'], static fn(string $id): bool => !$state['units'][$id]['isHero']));
        return $others >= 3 ? 'heroActivationRequired' : null;
    }

    public function victory(array $state): ?array
    {
        foreach ($state['seats'] as $seatId) {
            if (!Wounds::anyAlive($state, $seatId)) {
                return ['reason' => 'annihilation', 'winningSeatId' => self::other($state, $seatId)];
            }
        }
        return null;
    }

    public static function other(array $state, string $seatId): string
    {
        return $state['seats'][0] === $seatId ? $state['seats'][1] : $state['seats'][0];
    }

    private function draft(): DraftRules
    {
        if ($this->catalog === null) {
            throw new LogicException('The draft needs the catalog.');
        }
        return new DraftRules($this->catalog);
    }

    private static function alive(array $state, string $seatId): int
    {
        return count(array_filter(
            $state['units'],
            static fn(array $unit): bool => $unit['seatId'] === $seatId && $unit['hex'] !== null
        ));
    }

    private static function heroAlive(array $state, string $seatId): bool
    {
        foreach ($state['units'] as $unit) {
            if ($unit['seatId'] === $seatId && $unit['isHero'] && $unit['hex'] !== null) {
                return true;
            }
        }
        return false;
    }
}
```

`api/src/Rules/Vanilla/Schedule.php`:

```php
<?php
declare(strict_types=1);

namespace BloodAndBanners\Rules\Vanilla;

use BloodAndBanners\Rules\Vanilla\Modes\Modes;

/** Turn order as numbered slots per round; skipped slots take no turn and no turn number. */
final class Schedule
{
    public static function slotOf(array $state, string $seatId): int
    {
        $rules = Modes::ofState($state);
        for ($slot = 0; $slot < $rules->slotCount($state); $slot++) {
            if ($rules->seatAtSlot($state, $slot) === $seatId) {
                return $slot;
            }
        }
        return 0;
    }

    /** The next slot after $slot that takes a turn, wrapping into the next round. */
    public static function after(array $state, int $slot): int
    {
        $rules = Modes::ofState($state);
        $count = $rules->slotCount($state);
        for ($step = 1; $step <= $count; $step++) {
            $candidate = ($slot + $step) % $count;
            if ($rules->slotLive($state, $candidate)) {
                return $candidate;
            }
        }
        return $slot;
    }

    /** The turn number on which $seatId next starts a turn. */
    public static function nextTurnNumberOf(array $state, string $seatId): int
    {
        $turn = $state['turn'];
        if ($turn['activeSeatId'] === null) {
            return $turn['number'] + 1;
        }
        $rules = Modes::ofState($state);
        $slot = $turn['slot'] ?? self::slotOf($state, $turn['activeSeatId']);
        $count = $rules->slotCount($state);
        for ($step = 1; $step <= $count; $step++) {
            $slot = self::after($state, $slot);
            if ($rules->seatAtSlot($state, $slot) === $seatId) {
                return $turn['number'] + $step;
            }
        }
        return $turn['number'] + $count + 1;
    }
}
```

```php
<?php
declare(strict_types=1);

namespace BloodAndBanners\Rules\Vanilla\Modes;

use BloodAndBanners\Game\GameServiceException;
use BloodAndBanners\Rules\Vanilla\Catalog;
use BloodAndBanners\Rules\Vanilla\MatchEngine;
use BloodAndBanners\Rules\Vanilla\Terrain;

/** The Void Lord places monsters from a tier-point budget inside spawn zones, then confirms. */
final class CoopSetup
{
    public const COSTS = ['common' => 1, 'elite' => 2, 'boss' => 4];
    public const KINDS = ['placeMonster', 'removeMonster', 'confirmSetup'];
    private const MESSAGES = [
        'unsupportedCommand' => 'This command is not legal in the current game phase.',
        'notVoidLord' => 'Only the Void Lord sets up the monsters.',
        'unknownMonster' => 'That monster cannot be summoned.',
        'outsideSpawnZone' => 'Monsters can only be placed in a Void spawn zone.',
        'hexOccupied' => 'Another monster already stands there.',
        'hexNotEnterable' => 'A monster cannot be placed on that hex.',
        'budgetExceeded' => 'That monster costs more than the remaining budget.',
        'unknownUnit' => 'That monster is not on the battlefield.',
        'setupEmpty' => 'Place at least one monster before confirming.',
    ];

    public function __construct(private readonly Catalog $catalog)
    {
    }

    public static function cost(array $monster): int
    {
        return self::COSTS[$monster['tier']] ?? self::COSTS['common'];
    }

    public function legalActions(array $state, string $seatId): array
    {
        if ($seatId !== $state['voidLordSeatId']) {
            return [];
        }
        $actions = [];
        $remaining = $state['setup']['budget'] - $state['setup']['spent'];
        $free = self::freeSpawnHexes($state);
        $cheapest = min(array_map(self::cost(...), $this->catalog->monsters()) ?: [PHP_INT_MAX]);
        if ($free !== [] && $cheapest <= $remaining) {
            $actions[] = ['kind' => 'placeMonster', 'unitId' => null, 'targetHexes' => $free];
        }
        foreach ($state['units'] as $unitId => $unit) {
            $actions[] = ['kind' => 'removeMonster', 'unitId' => (string)$unitId, 'targetHexes' => [$unit['hex']]];
        }
        if ($state['units'] !== []) {
            $actions[] = ['kind' => 'confirmSetup', 'unitId' => null, 'targetHexes' => []];
        }
        return $actions;
    }

    public function apply(array $state, string $seatId, string $kind, array $payload): array
    {
        if (!in_array($kind, self::KINDS, true)) {
            self::fail('unsupportedCommand');
        }
        if ($seatId !== $state['voidLordSeatId']) {
            self::fail('notVoidLord');
        }
        $events = [];
        if ($kind === 'placeMonster') {
            $monster = $this->catalog->monster(self::text($payload, 'monster'));
            if ($monster === null) {
                self::fail('unknownMonster');
            }
            $hex = self::text($payload, 'hex');
            if (!isset($state['board'][$hex]) || $state['board'][$hex]['spawnZone'] !== 'void') {
                self::fail('outsideSpawnZone');
            }
            if (self::occupied($state, $hex)) {
                self::fail('hexOccupied');
            }
            if ($state['board'][$hex]['sightBlocker'] || Terrain::type($state['board'][$hex]) !== null) {
                self::fail('hexNotEnterable');
            }
            $cost = self::cost($monster);
            if ($state['setup']['spent'] + $cost > $state['setup']['budget']) {
                self::fail('budgetExceeded');
            }
            $unitId = 'v-m' . $state['setup']['nextMonster'];
            $state['setup']['nextMonster']++;
            $state['setup']['spent'] += $cost;
            $state['units'][$unitId] = [
                'unitId' => $unitId,
                'seatId' => $state['voidLordSeatId'],
                'side' => 'void',
                'isHero' => false,
                'tier' => $monster['tier'],
                'biome' => $monster['biome'],
                'name' => $monster['name'],
                'image' => $monster['image'],
                'move' => $monster['move'],
                'range' => $monster['range'],
                'power' => $monster['power'],
                'defense' => $monster['defense'],
                'hp' => $monster['hp'],
                'abilities' => [],
                'inactiveAbilities' => $monster['abilities'],
                'wounds' => 0,
                'hex' => $hex,
                'flags' => [],
            ];
            $events[] = MatchEngine::event('monsterPlaced', [$hex], ['unitId' => $unitId, 'monster' => $monster['name'], 'hex' => $hex, 'cost' => $cost]);
        } elseif ($kind === 'removeMonster') {
            $unitId = self::text($payload, 'unitId');
            $unit = $state['units'][$unitId] ?? null;
            if ($unit === null) {
                self::fail('unknownUnit');
            }
            $cost = self::cost($unit);
            $state['setup']['spent'] -= $cost;
            unset($state['units'][$unitId]);
            $events[] = MatchEngine::event('monsterRemoved', [$unit['hex']], ['unitId' => $unitId, 'monster' => $unit['name'], 'hex' => $unit['hex'], 'cost' => $cost]);
        } else {
            if ($state['units'] === []) {
                self::fail('setupEmpty');
            }
            $state['setup']['confirmed'] = true;
            $state['phase'] = 'draft';
            $state['draft']['pickingSeatId'] = $state['initiative']['order'][0];
            $state['draft']['pickIndex'] = 0;
            $events[] = MatchEngine::event('setupConfirmed', [], ['monsters' => count($state['units'])]);
        }
        return ['state' => $state, 'events' => $events];
    }

    private static function freeSpawnHexes(array $state): array
    {
        $free = [];
        foreach ($state['board'] as $key => $hex) {
            $key = (string)$key;
            if ($hex['spawnZone'] === 'void' && !$hex['sightBlocker'] && Terrain::type($hex) === null && !self::occupied($state, $key)) {
                $free[] = $key;
            }
        }
        sort($free, SORT_STRING);
        return $free;
    }

    private static function occupied(array $state, string $hex): bool
    {
        foreach ($state['units'] as $unit) {
            if ($unit['hex'] === $hex) {
                return true;
            }
        }
        return false;
    }

    private static function text(array $payload, string $key): string
    {
        $value = $payload[$key] ?? '';
        return is_string($value) ? $value : '';
    }

    private static function fail(string $code): never
    {
        throw new GameServiceException($code, self::MESSAGES[$code]);
    }
}
```

```php
    public const UNITS_PER_HERO_PLAYER = 8;
    private const MESSAGES = [
        'voidLordRequired' => 'A Co-op match needs a Void Lord.',
        'heroPlayerRequired' => 'A Co-op match needs at least one hero player.',
        'invalidCoopScenario' => 'This battlefield is not set up for Co-op.',
    ];

    public function __construct(private readonly ?Catalog $catalog = null)

    }

    public function start(array $seatIds, array $board, RandomSource $random, array $options): array
    {
        $voidLord = $options['voidLordSeatId'] ?? null;
        if (!is_string($voidLord) || !in_array($voidLord, $seatIds, true)) {
            self::fail('voidLordRequired');
        }

        if ($heroSeats === []) {
            self::fail('heroPlayerRequired');

        $layout = self::layout($board);
        $probe = array_map(static fn(int $i): string => "probe-{$i}", range(1, count($heroSeats) * self::UNITS_PER_HERO_PLAYER));

        $order = $initiative['order'];

        $budget = (int)($budgetRules['basePoints'] ?? 4) + (int)($budgetRules['pointsPerHeroPlayer'] ?? 8) * count($heroSeats);
        $state = [
            'mode' => 'coop',
            'phase' => 'setup',
            'seats' => $seatIds,
            'voidLordSeatId' => $voidLord,
            'sides' => [
                'heroes' => ['kind' => 'heroes', 'seatIds' => $order],
                'void' => ['kind' => 'void', 'seatIds' => [$voidLord]],

            'initiative' => ['rolls' => $initiative['rolls'], 'order' => $order],
            'setup' => ['budget' => $budget, 'spent' => 0, 'nextMonster' => 1, 'confirmed' => false],
            'draft' => [

                'pickIndex' => 0,
                'firstSeatId' => null,

            'effects' => [],
            'conditions' => [],
            'pending' => null,
            'turn' => Turn::idle(),
            'result' => null,

            'state' => $state,
            'events' => [MatchEngine::event('initiativeRolled', [], ['rolls' => $initiative['rolls'], 'order' => $order])],

    {
        return 2 * count($state['initiative']['order']);
    }

    public function seatAtSlot(array $state, int $slot): string
    {
        return $slot % 2 === 0 ? $state['initiative']['order'][intdiv($slot, 2)] : $state['voidLordSeatId'];

    public function activationError(array $state, string $unitId): ?string
    {
        return null;

    {
        return null;

    public static function layout(array $board): array

        foreach ($board as $key => $hex) {

        usort($facing, static fn(string $a, string $b): int => [Hex::distance($start, $a), $a] <=> [Hex::distance($start, $b), $b]);
        sort($spawn, SORT_STRING);
        return ['start' => $start, 'facing' => $facing[0], 'spawn' => $spawn];
```

```php
<?php
declare(strict_types=1);

namespace BloodAndBanners\Rules\Vanilla\Modes;

use BloodAndBanners\Game\GameServiceException;
use BloodAndBanners\Rules\Vanilla\Catalog;
use BloodAndBanners\Rules\Vanilla\MatchEngine;
use BloodAndBanners\Rules\Vanilla\Placement;
use BloodAndBanners\Rules\Vanilla\SnakeDraftOrder;
use BloodAndBanners\Rules\Vanilla\Turn;

/** Hero players snake-draft two heroes and one army each, then deploy around the shared start. */
final class CoopDraft
{
    private const KINDS = ['pickHero', 'pickArmy'];
    private const MESSAGES = [
        'unsupportedCommand' => 'This command is not legal in the current game phase.',
        'setupConfirmed' => 'The Void Lord has already confirmed the monsters.',
        'notYourPick' => 'It is not your pick.',
        'decisionAlreadyMade' => 'That decision has already been made.',
        'heroesComplete' => 'You already lead two heroes.',
        'unknownHero' => 'That hero is not in the catalog.',
        'unknownArmy' => 'That army is not in the catalog.',
        'heroTaken' => 'Another commander has already claimed that hero.',
        'armyTaken' => 'Another commander has already claimed that army.',
    ];

    public function __construct(private readonly Catalog $catalog)
    {
    }

    public function legalActions(array $state, string $seatId): array
    {
        if ($state['draft']['pickingSeatId'] !== $seatId) {
            return [];
        }
        return array_map(
            static fn(string $kind): array => ['kind' => $kind, 'unitId' => null, 'targetHexes' => []],
            self::openDecisions($state, $seatId)
        );
    }

    public function apply(array $state, string $seatId, string $kind, array $payload): array
    {
        if (in_array($kind, CoopSetup::KINDS, true)) {
            self::fail('setupConfirmed');
        }
        if (!in_array($kind, self::KINDS, true)) {
            self::fail('unsupportedCommand');
        }
        if ($state['draft']['pickingSeatId'] !== $seatId) {
            self::fail('notYourPick');
        }
        $draft = $state['draft'];
        if ($kind === 'pickHero') {
            if (count($draft['heroesBySeat'][$seatId]) >= 2) {
                self::fail('heroesComplete');
            }
            $value = self::text($payload, 'hero');
            if ($this->catalog->hero($value) === null) {
                self::fail('unknownHero');
            }
            foreach ($draft['heroesBySeat'] as $heroes) {
                if (in_array($value, $heroes, true)) {
                    self::fail('heroTaken');
                }
            }
            $draft['heroesBySeat'][$seatId][] = $value;
        } else {
            if ($draft['armyBySeat'][$seatId] !== null) {
                self::fail('decisionAlreadyMade');
            }
            $value = self::text($payload, 'army');
            if ($this->catalog->army($value) === null) {
                self::fail('unknownArmy');
            }
            if (in_array($value, $draft['armyBySeat'], true)) {
                self::fail('armyTaken');
            }
            $draft['armyBySeat'][$seatId] = $value;
        }
        $state['draft'] = $draft;
        $events = [MatchEngine::event('draftPicked', [], ['seatId' => $seatId, 'decision' => $kind, 'value' => $value])];

        $order = $state['initiative']['order'];
        $pickIndex = $draft['pickIndex'] + 1;
        $nextSeat = null;
        for ($offset = 0; $offset < count($order) * 2; $offset++) {
            $candidate = SnakeDraftOrder::seatAt($order, $pickIndex + $offset);
            if (self::openDecisions($state, $candidate) !== []) {
                $pickIndex += $offset;
                $nextSeat = $candidate;
                break;
            }
        }
        if ($nextSeat !== null) {
            $state['draft']['pickIndex'] = $pickIndex;
            $state['draft']['pickingSeatId'] = $nextSeat;
            return ['state' => $state, 'events' => $events];
        }
        $state['draft']['pickingSeatId'] = null;
        [$state, $placed] = $this->deploy($state);
        $events[] = MatchEngine::event('armiesPlaced', array_values($placed), ['units' => $placed]);
        return ['state' => $state, 'events' => $events];
    }

    private static function openDecisions(array $state, string $seatId): array
    {
        $open = [];
        if (count($state['draft']['heroesBySeat'][$seatId]) < 2) {
            $open[] = 'pickHero';
        }
        if ($state['draft']['armyBySeat'][$seatId] === null) {
            $open[] = 'pickArmy';
        }
        return $open;
    }

    private function deploy(array $state): array
    {
        $layout = CoopMode::layout($state['board']);
        $order = $state['initiative']['order'];
        $rosters = [];
        foreach ($order as $seatId) {
            $prefix = 's' . (array_search($seatId, $state['seats'], true) + 1);
            $roster = [];
            foreach ($state['draft']['heroesBySeat'][$seatId] as $index => $hero) {
                $roster[$prefix . '-hero' . ($index + 1)] = ['isHero' => true] + $this->catalog->hero($hero);
            }
            foreach ($this->catalog->army($state['draft']['armyBySeat'][$seatId])['units'] as $index => $stats) {
                $roster[$prefix . '-u' . ($index + 1)] = ['isHero' => false] + $stats;
            }
            $rosters[$seatId] = $roster;
        }
        $interleaved = [];
        for ($round = 0; $round < CoopMode::UNITS_PER_HERO_PLAYER; $round++) {
            foreach ($order as $seatId) {
                $ids = array_keys($rosters[$seatId]);
                if (isset($ids[$round])) {
                    $interleaved[] = $ids[$round];
                }
            }
        }
        $occupied = array_fill_keys($layout['spawn'], true);
        foreach ($state['units'] as $unit) {
            $occupied[$unit['hex']] = true;
        }
        $positions = Placement::place($state['board'], $layout['start'], $layout['facing'], $interleaved, $occupied);
        $placed = [];
        foreach ($rosters as $seatId => $roster) {
            foreach ($roster as $unitId => $stats) {
                $state['units'][$unitId] = ['unitId' => $unitId, 'seatId' => $seatId, 'side' => 'heroes'] + $stats
                    + ['wounds' => 0, 'hex' => $positions[$unitId], 'flags' => []];
                $placed[$unitId] = $positions[$unitId];
            }
        }
        ksort($state['units'], SORT_STRING);
        ksort($placed, SORT_STRING);
        $state['phase'] = 'active';
        $state['turn'] = Turn::fresh($state, $order[0], 1, 0);
        return [$state, $placed];
    }

    private static function text(array $payload, string $key): string
    {
        $value = $payload[$key] ?? '';
        return is_string($value) ? $value : '';
    }

    private static function fail(string $code): never
    {
        throw new GameServiceException($code, self::MESSAGES[$code]);
    }
}
```

```php
    private function applyLobbyCommand(array $game, array $membership, string $identityId, array $command, int $newVersion): void
    {
        $currentVersion = (int)$game['version'];
        $kind = (string)$command['kind'];
        $payload = is_array($command['payload']) ? $command['payload'] : [];
        if ($kind === 'setReady') {
            if (!is_bool($payload['ready'] ?? null)) {
                throw new GameServiceException('unsupportedCommand', 'This command is not legal in the current game phase.', $currentVersion);
            }
            if ($game['lifecycle'] !== 'lobby') {
                throw new GameServiceException('illegalLifecycle', 'Readiness can only change in the lobby.', $currentVersion);
            }
            $this->connection->prepare(
                'UPDATE game_memberships SET ready = :ready WHERE game_id = :game AND identity_id = :identity'
            )->execute(['ready' => $payload['ready'] ? 1 : 0, 'game' => $game['id'], 'identity' => $identityId]);
            $this->bumpVersion($game['id'], $currentVersion, $newVersion);
            $this->appendEvent($game['id'], $newVersion, 'readinessChanged', $identityId, ['ready' => $payload['ready']]);
            return;
        }
        if ($game['mode'] !== 'coop' || $game['lifecycle'] !== 'lobby') {
            throw new GameServiceException('unsupportedCommand', 'This command is not legal in the current game phase.', $currentVersion);
        }
        $memberships = $this->memberships($game['id']);
        $current = null;
        foreach ($memberships as $seat) {
            if ($seat['role'] === 'voidLord') {
                $current = (string)$seat['id'];

        }
        if ($kind === 'claimVoidLord') {
            if ($current !== null && $current !== (string)$membership['id']) {
                throw new GameServiceException('voidLordTaken', 'Another commander is already the Void Lord.', $currentVersion);
            }

        } elseif ($kind === 'releaseVoidLord') {

            }

                throw new GameServiceException('seatNotFound', 'The requested seat does not exist.', $currentVersion);

        if ($bump->rowCount() === 0) {
            throw self::versionConflict($currentVersion);
```

```csharp
namespace BloodAndBanners.UI.Services;

using BloodAndBanners.Contracts;

/// <summary>How Co-op screens name seats: the viewer is "You", the Void Lord by role, hero players by banner number.</summary>
public static class SeatNames
{
    public static bool IsVoidLord(GameProjection projection, string? seatId) =>
        seatId is not null && projection.Memberships.Any(member => member.SeatId == seatId && member.Role == "voidLord");

    public static string Coop(GameProjection projection, string? seatId)
    {
        if (seatId is null)
        {
            return "A commander";
        }
        if (seatId == projection.Viewer.SeatId)
        {
            return "You";
        }
        if (IsVoidLord(projection, seatId))
        {
            return "Void Lord";
        }
        var seat = projection.Memberships.FirstOrDefault(member => member.SeatId == seatId);
        return seat is null ? "A commander" : $"Commander {seat.SeatIndex}";
    }

    public static string? SideOf(GameProjection projection, string? seatId) =>
        seatId is null
            ? null
            : projection.Sides?.FirstOrDefault(side => side.Value.SeatIds.Contains(seatId)).Key ?? seatId;
}
```
